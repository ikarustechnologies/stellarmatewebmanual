.. section:: Rustdesk

StellarMate is shipped with Rustdesk Remote Control software. RustDesk is a free, open-source remote desktop tool that offers fast, secure, and user-friendly remote access to computers across various platforms. It prioritizes user privacy with end-to-end encryption and is suitable for both casual and professional users.
The difference between Rustdesk and VNC is that Rustdesk can be used over the internet without having to open any ports on the router. You can use Rustdesk to access StellarMate desktop remotely over the internet. In the StellarMate App, you can toggle Rustdesk service and copy the Rustdesk ID.

.. image:: /_static/images/ekos/tabs/Device/remote-support/remote-id.jpg
  :width: 400px
  :align: center

Download the Rustdesk client on MacOS, Windows, Android, or Linux and use the Rustdesk ID and password to remotely access your unit. By default, the password is stellar@Mate123!
It is highly recommended to change the Rustdesk password after enabling the service.
