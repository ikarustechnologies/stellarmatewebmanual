.. subsection:: Meade

INDI supports all Meade mounts via a number of drivers tailored to each model family (Classic, GPS..etc). The only mount that is NOT support is Meade LS since it uses a serial chip that fails to work with Linux & MacOS. There is no support from Meade on Meade LS.
